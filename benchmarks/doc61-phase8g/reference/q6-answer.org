#+title: q6 reference answer

機器は *DGR*。

完全地絡時の対地電圧は *3810V* と扱う。
これは

#+begin_example
6600 / √3 = 3810V
#+end_example

であり、*EVT* による仮想接地があっても、
*電技解釈 第15条* では「電位変成器を用いて中性点を接地するものは、中性点非接地式とみなす」
ためである。

5% タップの動作印加電圧は

#+begin_example
3810V × 0.05 = 190.5V
#+end_example

Io 試験時の 150% 電圧は

#+begin_example
190.5V × 1.5 = 285.75V
#+end_example

であり、KB の整理値に合わせれば *285.3V* として扱う。

また、年次点検ノートでは DGR の判定基準として *JIS C 4601* が挙がっている。
