#+title: q2 reference answer

対象は *公称6.6kVの高圧 CV ケーブル*。
まず最大使用電圧は

#+begin_example
6600 × 1.15 / 1.1 = 6900V
#+end_example

となる。

6.6kV 高圧電路の交流絶縁耐力試験電圧は

#+begin_example
6900V × 1.5 = AC 10350V
#+end_example

である。

さらに、*電技解釈 第16条* 系の整理では、ケーブルを使う機械器具の接続線等は
交流耐圧の *2倍の直流電圧* に置き換えられるため、直流試験電圧は

#+begin_example
10350V × 2 = DC 20700V
#+end_example

となる。

ただし *LA 内蔵 PAS* が接続されている場合は、避雷器が放電して破損するおそれがある。
したがって *ケーブルと PAS を切り離す* か、*交流耐電圧試験(10350V)で実施する*。

補足として、竣工検査メモでも「トランスは交流、高圧ケーブルは直流でもよい」と整理されている。
