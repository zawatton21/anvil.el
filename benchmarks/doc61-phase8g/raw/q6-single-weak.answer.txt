この問題は、6.6kV非接地系における接地故障保護（DGR：接地故障継電器）の設定値計算です。体系的に解きます。

## 計算と根拠

### 1. **動作印加電圧**

**答え：約190.5V（≈191V）**

**計算式：**
```
動作印加電圧 = 5% × 相電圧
           = 5% × (6600V / √3)
           = 5% × 3810V
           ≈ 190.5V
```

**根拠：**
- 6.6kV系の相電圧 = 6600V ÷ √3 ≈ 3810V
- DGRのタップは相電圧に対する百分率で設定される（電気技術基準 第38条関連）
- 非接地系での地絡保護では相電圧基準が用いられる

---

### 2. **Io試験時 150% 条件での印加電圧**

**答え：約285.75V（≈286V）**

**計算式：**
```
150%条件電圧 = 150% × 動作印加電圧
            = 150% × 190.5V
            ≈ 285.75V
```

**試験根拠：**
- JIS C 6802（継電器の一般要件と試験方法）
- 150%は確実な動作を検証するための過動作域テスト
- この電圧で印加時、継電器が確実に動作することを確認

---

### 3. **完全地絡時対地電圧 3810V の根拠**

**答え：3810V = 6600V ÷ √3 = 相電圧**

| 項目 | 値 |
|------|-----|
| 系統線間電圧 | 6600V |
| 相電圧（中性点からの電圧） | **3810V** |
| 非接地系での対地電圧 | 相電圧と等しい |

**現象と根拠：**

**機器と組み合わせ：**
- **DGR（接地故障継電器）** - 零相電圧検出
- **ZCT（零相変流器）** - 零相電流検出
- **E/G変圧器**（接地変圧器）- 零相電圧発生

**根拠条文：**

1. **電気技術基準 第38条**  
   → 非接地系統での定義：「中性点が接地されていない系統」

2. **JIS C 6802**  
   → 継電器の過負荷試験として150%条件を規定

3. **電力系統の地絡現象の物理原理：**
   ```
   一相地絡発生時：
   - 故障相の対地電圧 → 0V（地絡点）
   - 健全相の対地電圧 → √3 × 相電圧相当
   - 従って、健全相の最大対地電圧 = 3810V
   ```

---
