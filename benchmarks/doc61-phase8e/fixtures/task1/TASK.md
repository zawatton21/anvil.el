# タスク: strutil ライブラリの補完

`strutil-core.el` と `strutil-format.el` は小さな文字列ユーティリティ集です。
以下の3点を修正・実装してください。

1. **`strutil-truncate`** — docstring 通りなら「S を N 文字以内（省略記号
   `...` を含めて）に切り詰める」はずですが、現状は N 文字を超えた文字列を
   返してしまいます。省略記号を含めた合計が必ず N 文字以内になるよう修正
   してください。S が既に N 文字以内ならそのまま返す挙動は変更不要です。

2. **`strutil-display-width`** — 日本語などの全角文字を含む文字列の「表示
   幅」を計算する関数ですが、現状は単純な文字数 (`length`) を返している
   だけで、全角文字を考慮していません。全角文字 (`strutil-wide-char-p` が
   non-nil を返す文字) は2カラム、それ以外は1カラムとして幅を計算するよう
   修正してください。`strutil-wide-char-p` 自体は変更不要です。

3. **`strutil-join-nonempty`** — `tests/visible-test.el` から呼び出されて
   いますが、まだ定義されていません。リストの各要素のうち `nil` または
   空文字列を除外し、残りを SEP で連結する関数として新規実装してください
   （シグネチャ: `(strutil-join-nonempty strings sep)`）。

スコープ外: 上記3点以外の関数の挙動変更や、新規ファイルの追加は不要です。

完了条件: `make check` が全てパスすること。
