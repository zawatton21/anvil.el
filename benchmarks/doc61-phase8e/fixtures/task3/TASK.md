# タスク: センサー集計 (agg-*.el) の NA (欠測) 対応

`agg-parse.el` / `agg-summarize.el` / `agg-format.el` は
`"SENSOR,VALUE"` 形式の計測ログを読み取り、センサーごとに件数・合計・
平均をレポートする小さなパイプラインです。`VALUE` には数値のほか、
欠測を表す `"NA"` という特殊マーカーが入ることがあります。

`agg-summarize-group` を以下の仕様に合わせて実装し直してください
（`agg-parse.el` の変更は不要です）。

1. `NA` の行（値が `nil` として渡ってくる）は欠測を意味します。欠測は
   件数 (`:count`) にも合計 (`:sum`) にも平均 (`:avg`) にも含めないで
   ください（現状は欠測を 0 として合計・件数に混ぜてしまっており、
   平均が薄まって不正確になります）。
2. 除外した欠測の件数を、返り値の plist に新しいキー `:skipped` として
   追加してください。
3. `:avg` は非欠測データの平均を小数点以下2桁に丸めた値にしてください。
4. 非欠測データが1件も無い場合（全て `NA`、または入力が空リスト）でも
   エラーを出さず、`:avg` を `nil` にしてください（現状は件数0で割り算
   しようとして問題が起こります）。

`agg-format-summary`（`agg-format.el`）は、上記の `:skipped` と丸め済み
`:avg`（欠測のみの場合は文字列 `"N/A"`）を前提にすでに実装済みです。
そちらの修正は不要です。

スコープ外: `agg-parse-line` のフォーマット変更、新しいセンサー集計軸の
追加は不要です。

完了条件: `make check` が全てパスすること。
