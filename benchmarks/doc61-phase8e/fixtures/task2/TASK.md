# タスク: チケットワークフロー (flow.el) の仕様適合

`flow.el` はサポートチケットの状態遷移を管理する簡易ステートマシンです。
ファイル冒頭のコメントに遷移表（仕様）が書かれています。この仕様と実際の
実装 (`flow-transitions` 変数の中身) を1エントリずつ突き合わせ、次を満たす
よう修正してください。

1. `resolved` 状態から `reopen` イベントで `reopened` 状態へ遷移できること。
   仕様には書かれていますが、現在の `flow-transitions` には対応する
   エントリがありません。

2. それ以外にも、コメントの遷移表と `flow-transitions` の実装内容が
   食い違っている箇所がないか確認し、あれば仕様（コメント側）が正しい
   ものとして実装を直してください。

`flow-apply` / `flow-make` / `flow-transition` / `flow-terminal-p` の
シグネチャは変更しないでください。`flow-report.el` 側の修正は想定して
いません。

スコープ外: 新しい状態やイベントの追加、エラー型の変更は不要です。

完了条件: `make check` が全てパスすること。
