# タスク: calc ミニ計算機に単項マイナスを追加する

`calc-*.el` は小さな四則演算ライブラリです。現在は二項演算子
`+ - * ^` と括弧だけを扱えますが、**prefix の単項マイナス**は未対応です。

やってほしいこと:

1. `-3 + 5` や `2 * -3` のような式が評価できるようにしてください。
2. 優先順位は repo の `README.org` の説明に合わせてください。
   特に `-2^2` は `(-2)^2` ではなく `-(2^2)` として扱う必要があります。
3. 単項マイナス導入後は `1--2` のような「隣接する演算子」も意味を持つので、
   tokenization から parser/evaluator まで一貫して動くようにしてください。

注意:

- 仕様は `README.org`、各 docstring、`tests/visible-test.el` のコメントに分散
  しています。どこか1ファイルだけ見て直すと取りこぼします。
- `calc-parse.el` の優先順位処理は、そのまま `-` を足すと壊れやすい構造です。
  必要なら小さく内部 API を整理してください。

スコープ外:

- 新しい演算子の追加
- 小数対応
- エラー型や public 関数名の変更

完了条件: `make check` が全てパスすること。
